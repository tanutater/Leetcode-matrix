# 🚀 LeetMetric – LeetCode Performance Dashboard

LeetMetric is a clean and interactive web-based dashboard that visualizes LeetCode user statistics in a structured and aesthetic way.

🔗 GitHub Repository:  
https://github.com/tanutater/Leetcode-matrix

---

## 📌 About The Project

LeetMetric is a frontend-based dashboard that fetches and displays LeetCode user statistics dynamically.

It provides:

- ✅ Overall Submissions  
- 📊 Total Questions  
- 🏆 Contribution Points  
- 📈 Ranking  
- 📦 Difficulty-wise solved problems (Easy / Medium / Hard)  

This project was built to strengthen core frontend concepts including DOM manipulation, API handling, and dynamic UI rendering.

## 🧠 How It Works

1. User enters a LeetCode username.
2. JavaScript fetches user statistics using an API.
3. The response is parsed and stored.
4. Cards are dynamically generated using JavaScript.
5. Statistics are displayed in a structured dashboard format.

1. Clone the repository:
